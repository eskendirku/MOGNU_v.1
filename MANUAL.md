# Руководство пользователя: Анализатор задачи «9 точек» (SIGMA-2.0)

Интерактивный комплекс для исследователей когнитивной психологии, предназначенный для автоматизированного анализа, калибровки, сегментации и статистической обработки траекторий решения классической задачи «9 точек» (Nine Dots Puzzle).

---

## 1. Способы запуска и доступ

Программа разработана как полностью клиентское веб-приложение (Single Page Application). Все расчеты производятся локально в вашем браузере: данные не отправляются на сторонние серверы, что гарантирует полную конфиденциальность экспериментов.

### Онлайн-доступ (в любом браузере)
Сайт опубликован и доступен по адресу:
👉 **[https://eskendirku.github.io/SIGMA-2.0/](https://eskendirku.github.io/SIGMA-2.0/)**

> [!TIP]
> При первом открытии или после обновлений нажмите `Ctrl + F5` (или `Cmd + Shift + R`), чтобы сбросить кеш браузера.

### Локальный запуск на компьютере
В папке проекта `Desktop/GEM_phd/новый обработчик`:
1. Дважды кликните по файлу **`_START_PHD1.bat`** (автоматически запустит сервер и откроет браузер).
2. Либо в терминале выполните:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:3000`.

## 2. Подготовка и загрузка экспериментальных данных

Программа **не требует ручной очистки файлов** и поддерживает как необработанные «сырые» выгрузки экспериментальных программ (OpenSesame, PsychoPy и др.), так и очищенные таблицы.

### Поддерживаемые форматы и структура CSV
- **Формат файла:** `.csv` с разделителем «запятая» (`,`) или «точка с запятой» (`;`).
- **Кодировка:** `UTF-8` или `Windows-1251` (определяется автоматически).
- **Координаты 9 точек:** распознаются по признаку `isElement === 1`. Программа автоматически находит 9 точек стимула, центрирует их на холсте и вычисляет межточечный интервал ($dx$, $dy$).
- **Траектории проб:** строки с `isElement === 0` (строки инициализации экрана с `seconds` автоматически фильтруются).

### Автоматически распознаваемые столбцы метаданных
Все метаданные испытуемого считываются **однократно** из первой строки файла (даже если экспериментальная программа дублирует их в каждой из 1000+ строк):

| Столбец в CSV | Распознаваемые имена в заголовке | Назначение |
| :--- | :--- | :--- |
| **Фамилия** | `surname`, `lastname`, `last_name`, `фамилия` | Фамилия испытуемого (выводится в отчеты) |
| **Имя** | `name`, `firstname`, `first_name`, `имя` | Имя испытуемого |
| **Единое ФИО** | `name`, `фио`, `fio`, `full_name` | Если указано «Иванов Иван», автоматически делится на Фамилию и Имя |
| **Пол** | `gender` | `0`/`ж`/`female` $\rightarrow$ «женский», `1`/`м`/`male` $\rightarrow$ «мужской» |
| **Возраст** | `age` | Возраст в годах |
| **Опыт решения** | `solvedBefore` | Решал ли испытуемый задачу до эксперимента |
| **Инсайт** | `insight` | Оценка внезапности / ощущения озарения при решении |
| **Общее время** | `totaltasktime` | Общее суммарное время решения задачи в секундах |
| **Шкалы опросника** | `Удовольствие`, `Удивление`, `Внезапность`, `Облегчение`, `Уверенность`, `Драйв`, `slider...` | Числовые баллы психологических шкал |
| **Группа** | `group` | Экспериментальная группа (контрольная, подсказка и др.) |

> [!NOTE]
> Если столбцы имени и фамилии отсутствуют, в качестве фамилии используется имя загруженного файла (Subject ID), а имя остается пустым.

### Процесс загрузки
1. В левой панели найдите блок **«Загрузка»**.
2. Перетащите один или сразу несколько CSV-файлов в пунктирную область (Drag & Drop) либо нажмите **«Выбрать CSV файлы»**.
3. Испытуемые появятся в списке в левой колонке с отображением ФИО, ID и количества валидных проб.

## 3. Интерфейс и возможности анализа

```
+-----------------------------------------------------------------------------------+
|  [Список испытуемых]   |          [Холст 800x800]           |  [Панель фильтров]  |
|  - Иванов Иван (8 проб)|  (1) -------- (2) -------- (3)     |  - Типы линий       |
|  - Петров П.  (12 проб)|   | \                       |      |  - Старт / Финиш    |
|                        |  (4) -------- (5) -------- (6)     |  - Ручные правки    |
|  [Карточка субъекта]   |   |            | \          |      +---------------------+
|  - ФИО (редактируемое) |  (7) -------- (8) -------- (9)     |  [Экспорт CSV]      |
|  - Группа              |                                    |  - Отфильтрованные  |
|  - Пол / Возраст       |  Режим калибровки:                 |  - Все данные       |
|  - Опросник и шкалы    |  [←][↑][↓][→] перенос линий        |  - Сводная матрица  |
+-----------------------------------------------------------------------------------+
```

### 1. Выбор испытуемого и редактирование карточки
- Клик по испытуемому в левом списке открывает его попытки.
- В блоке **«Информация»** можно прямо в интерфейсе отредактировать:
  - **Фамилию** и **Имя** (изменения сразу отобразятся в интерфейсе и пойдут в экспорт).
  - **Группу** испытуемого (например, `Инверсия`, `Контроль`).
- Кнопка с кубком 🏆 позволяет пометить испытуемого как «Решил» или «Не решил».

### 2. Холст и визуализация попыток
- 9 точек занумерованы от 1 до 9 (1–3 верхний ряд, 4–6 средний, 7–9 нижний).
- В нижней панели можно переключать пробы (кнопки **«Предыдущая»** / **«Следующая»** или выбор из выпадающего списка).
- **Дополнительные слои визуализации:**
  - **Точки излома (Breakpoints):** отображает вершины линий, где испытуемый менял направление движения.
  - **Тепловая карта (Heatmap):** наложение всех линий испытуемого для оценки плотности поиска.
  - **Финишная карта:** распределение точек окончания попыток по узлам.
  - **Анимация (Play):** воспроизведение процесса рисования с учетом реальных временных меток (`time2`).

## 4. Калибровка решений (Смещение и выравнивание)

В экспериментах координаты нарисованных линий могут быть смещены относительно матрицы из-за разрешения экрана или индивидуального стиля рисования.

### Принцип работы калибровки в программе
> [!IMPORTANT]
> **9 точек матрицы неподвижны** и строго центрированы в точке $(400, 400)$.  
> В режиме калибровки перемещается **само нарисованное решение** испытуемого.

### Инструкция по калибровке:
1. Выберите пробу, требующую центрирования, и нажмите кнопку **«Калибровка»** (иконка перекрестия).
2. **Перемещение мышью:** зажмите левую кнопку мыши на холсте и двигайте решение в нужную сторону.
3. **Точная подгонка клавишами стрелок:**
   - `←` `→` `↑` `↓` — смещение на **1 пиксель**;
   - `Shift` + стрелки — смещение с шагом **10 пикселей**.
4. **Параметры в панели:**
   - **Смещение X / Y:** точные числовые координаты сдвига.
   - **Масштаб (Scale):** пропорциональное сжатие/растяжение траектории (1.0 = 100%).
   - **Радиус AoI (Hit Padding):** зона захвата узла в пикселях (по умолчанию 15px). Если линия проходит в пределах этого расстояния от точки, узел считается посещенным.
5. При смещении линии программа **мгновенно в реальном времени пересчитывает**:
   - Посещенные узлы (`NodesVisited`).
   - Автоматическую классификацию типа каждой линии.

## 5. Классификация линий и ручное переопределение

### Автоматические типы линий
Каждая линия траектории сегментируется по углам поворота и автоматически относится к одному из 8 типов:
1. **Боковая:** соединяет соседние внешние точки по периметру матрицы (например, 1-2, 2-3, 3-6).
2. **Центральная:** проходит строго через центральную точку 5 горизонтально или вертикально (2-5-8, 4-5-6).
3. **Диагональная:** соединяет угловые точки через центр (1-5-9, 3-5-7).
4. **Хордовая:** соединяет крайнюю и среднюю точки противоположных сторон.
5. **Хорды длинные:** пересекает матрицу под углом через несмежные узлы.
6. **Касательная:** линия, задевающая матрицу с выходом за внешний контур.
7. **Внешняя:** полностью лежит за пределами квадрата 9 точек.
8. **Прочая:** сложная, не попавшая в стандартные категории линия.

### Ручное переопределение (Manual Override)
Если исследователь видит, что алгоритм из-за погрешности руки испытуемого классифицировал линию неточно:
- В карточке пробы можно нажать кнопку переопределения и присвоить линии нужный статус (в файл экспорта попадет пометка `IsManualOverride: true` и тип `прочая`/скорректированный).

## 6. Фазовый анализ (Phased Mode)

Для изучения динамики инсайта программа поддерживает автоматическую разбивку процесса решения каждого испытуемого на 3 равные фазы:
- **`Beg` (Начальная фаза):** первые попытки, исследование внутри матрицы 9 точек.
- **`Mid` (Промежуточная фаза):** фаза плато и тупика.
- **`End` (Финальная фаза):** пробы непосредственно перед нахождением решения или выходом за пределы квадрата.

Все метрики (время, типы линий, выходы за матрицу, повороты вне точек) рассчитываются как суммарно, так и индивидуально для каждого из трех периодов.

## 7. Экспорт данных и отчетов

В правой панели доступны три кнопки экспорта в формате `.csv`:

### 1. Экспорт (CSV) — Filtered Export
Выгружает только текущий видимый срез данных в соответствии с активными фильтрами (по типам линий, стартовым точкам или конкретному испытуемому).

### 2. Все данные (All Data CSV)
Полная детализированная таблица по всем испытуемым и всем пробам. Каждая строка — один отдельный отрезок линии.
- **Содержит:** `LastName`, `FirstName`, `Age`, `Gender`, `SolvedBefore`, `Insight`, `totalTaskTime`, `SubjectId`, `Group`, `TrialId`, координаты начала/конца отрезка ($X_1, Y_1, X_2, Y_2$), посещенные точки (`1-2-3`), признаки старта/финиша в точках, параметры калибровки.

### 3. Статистика (Summary Statistics CSV)
Основной файл для математической статистики (SPSS, R, Python, Jamovi).  
Каждая строка — **один испытуемый**:
- **Паспортные данные:** Фамилия, Имя, Возраст, Пол, Группа, Статус решения (0/1).
- **Результаты опросника:** `SolvedBefore`, `Insight`, `totalTaskTime`, индивидуальные колонки для каждой шкалы (`Scale_Удовольствие`, `Scale_Удивление` и др.).
- **Интегральные метрики решения:**
  - Общее количество проб (`TrialsCount`) и линий (`LinesCount`).
  - Среднее время попытки (`mean_trial_time_ms`) и общее время (`total_solution_time_ms`).
  - Характеристики первого шага: стартовая/финишная точка первой попытки, тип первой линии.
  - Характеристики успешного решения: точки старта и финиша финального решения.
- **Метрики выхода за рамки (Out-of-the-box):**
  - Абсолютное и относительное число линий, начатых вне матрицы (`LinesStartOutsideMatrixAbs`, `Rel`).
  - Абсолютное и относительное число линий, завершенных вне матрицы (`LinesFinishOutsideMatrixAbs`, `Rel`).
  - Линии через 3, 2, 1 точку (абсолютные и относительные частоты).
- **Повороты:** общее число поворотов, повороты вне точек стимула (`NonDotTurns`), коэффициент поворотов вне точек (`NonDotTurnsRatio`).
- **Частоты типов линий:** общее распределение и распределение в позициях 1, 2, 3, 4 (`Pos1_Type_боковая` и др.).
- **Полная матрица фазового анализа:** блоки колонок с префиксами `Beg_`, `Mid_`, `End_` со всеми перечисленными метриками для каждого периода решения.

## 8. Сохранение и загрузка сессий (JSON)

Чтобы не калибровать и не размечать пробы заново при следующем открытии программы:
- Нажмите **«Сохранить сессию»** — программа выгрузит файл `.json`, содержащий всех загруженных испытуемых, установленные смещения калибровки, отредактированные ФИО, группы и ручные метки.
- Для продолжения работы нажмите **«Загрузить сессию (JSON)»** в блоке загрузки и выберите сохраненный файл — рабочее пространство полностью восстановится.
